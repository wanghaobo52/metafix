# 音频标签补全

一个脚本 + 一个同目录的核心库，给音频文件补上歌名、歌手、专辑、音轨号、封面。
**不重新编码**，音频数据一个字节都不动，只改标签。

## 文件

| 文件 | 作用 |
|---|---|
| `metafix.sh` | 入口脚本 |
| `libmetacore.so` | 精简版 FFmpeg，只做解封装和重新封装，2.3 MB |

两个必须放在同一个文件夹里。`.so` 其实不是动态库，是个完整的静态二进制，只是沿用
这个扩展名。

这是从「音频转换」项目里拆出来的独立版本。核心库专门为改标签编的，砍掉了所有
编码器（不能转格式，也不需要转），所以比转码版小一圈。就算你把两个项目的文件混
在一个目录里也不会打架——脚本优先找 `libmetacore.so`，找不到才回退用
`libmediacore.so`。

## 用法

    sh metafix.sh                         # 交互向导
    sh metafix.sh 洛天依 - 世末歌者.mp3      # 补这一首
    sh metafix.sh -r 音乐目录/              # 整个目录递归补
    sh metafix.sh -n -r 目录/               # 只体检，列出缺什么，不改文件
    sh metafix.sh --from 模板.flac 目标.mp3   # 把模板的标签整体抄过去
    sh metafix.sh --artist 某某 --album 某某 目录/
    sh metafix.sh -b 目录/                  # 改前备份到 ./修复前备份/

不给参数时走交互向导，会问标签从哪来：

    1) 从文件名猜（歌手 - 歌名.mp3）
    2) 从另一个文件复制（模板）
    3) 我手动填

## 只补缺的

默认**不覆盖已有的标签**。文件已经有歌名就跳过，只补缺的那几项。想强制覆盖加 `-f`。

这条规则的好处是：一首歌你手动改过歌手，再跑一遍批量补全不会被文件名覆盖回去。

## 文件名解析

按顺序尝试，认出多少填多少：

    "歌手 - 标题.mp3"     → 歌手=歌手  标题=标题
    "01 - 标题.mp3"       → 音轨=01    标题=标题
    "01. 标题.mp3"        → 音轨=01    标题=标题
    "01_标题.mp3"         → 音轨=01    标题=标题
    "标题.mp3"            → 标题=标题

只认开头三位以内的数字当音轨号，所以「2024 年度精选.mp3」不会被误认成第 202 首。

## 安全措施

**先写临时文件，成功后才替换。** 处理过程中出错，原文件一个字节都没动。目标文件
是 `同目录/原文件名.metafix_随机数.tmp.扩展名`，成功后原子替换。

**`-n` 体检模式完全不写盘。** 想知道批量补全会影响哪些文件，先跑 `-n` 看一眼。

**`-b` 会先备份。** 备份放在输出目录下的 `修复前备份/`，文件名不变。

**脚本不会删你的核心库。** 临时目录里的副本用完会清掉，但同目录的
`libmetacore.so` 永远不动。

## 支持的文件

mp3、flac、m4a、mp4、wav、ogg、aac、wma、ape、mka

标签和封面在这几种容器之间是通的：mp3 的 ID3v2、flac 的 Vorbis comment、m4a 的
iTunes atom、封面分别是 APIC / picture block / covr atom。

## 几点说明

**为什么不能转格式。** 改标签靠的是「解封装 → 重新封装」，音频流原样搬过去。如果
换个容器导致编码不兼容（比如 mp3 塞进 m4a），重新封装会失败——这不是 bug，是这
类工具的固有边界。要转格式请用「音频转换」那个项目。

**ogg 不支持内嵌封面。** 给 ogg 补封面会失败，脚本会跳过封面只补文字标签。

**为什么不在原地直接运行。** 安卓的 `/sdcard` 是 noexec，不允许执行里面的程序。脚
本会自动把核心库复制到可执行的临时目录再运行，用完删掉。

**`.aac` 的时长可能显示得很离谱。** ADTS 容器没有全局头，时长只能按首帧码率估算，
首帧若是静音就会估偏。文件本身是好的。

## 技术细节

- FFmpeg 7.1 静态构建，只编入解封装器、复用器和参数探测所需的解码器
- 不含任何编码器（所以不能转码），不含 LAME
- musl 静态链接，不依赖系统库
- 核心命令：`mediacore -probe <文件>` 读标签，`mediacore -copy <输入> <输出> k=v...` 写标签
